So the NH's δ¹³C anomaly per ppm of CO₂ excess is ~2× too depleted: either the **isotopic source contrast** is too strong, or the **isotopic damping** (gross exchange with land and ocean, which relaxes δ¹³C anomalies faster than CO₂ anomalies because gross fluxes are ~10× net) is too weak — and too weak preferentially in the NH, where the land is.

## 2. Candidate mechanisms, cheapest test first (all conditional scans at the canonical, C++ core, seconds each; then a refit of the winner)
Read EVERY one on the same panel: gate H (R_co2, R_d13c, contrast z), gate GL, gate Q, the δ¹³C Suess trend (obs − model at MLO 1990–2020), the two `d13c_level_*` and `d13c_seasonal_*` rows, `q10`'s conditional optimum, and the 26-row likelihood. A mechanism that fixes the gradient by re-breaking the Suess trend or the seasonal δ¹³C is not a fix.

1. **The land gross isotope loop is OFF: `ra_ratio = 0`** (`R/model.R` ~1245: "Ra/NPP routed THROUGH the vegetation pool… 0 = no gross loop… affects isotopes only… the value is for the ¹⁴C data to choose" — built 08-12, never fitted, never scanned against the gradient). With it off, the land damps δ¹³C anomalies only at the NET NPP rate (60 GtC/yr PI); real GPP ≈ 2× NPP and the part cycling through the pools returns the pool's ratio — the ocean-gross-exchange analog. **The land is NH-heavy (`npp_frac_NH` 0.60), so this damping is exactly the NH-preferential one the gradient needs.** Test: `ra_ratio ∈ {0, 0.25, 0.5, 1, 2}` at the canonical → R_d13c, the Suess trend, `d13c_seasonal_MLO` (a bigger gross loop also moves the NH seasonal δ¹³C amplitude — it is the same physics), the bomb Δ¹⁴C rows (the loop moves ¹⁴C too — the reason the ¹⁴C data was to choose it). **Prediction if this is it:** R_d13c falls toward 1 with R_co2 unchanged, gate Q improves (less atmospheric depletion to disequilibrate against), and the Suess trend flattens toward obs — all three defects the 09-04 assessment "joined into one" move together. If R_d13c barely moves at `ra_ratio` 2, the land loop is not the lever.
2. **The fossil δ¹³C signature and its hemispheric placement.** `d13c_foss` is in the forcing table (time-varying since 08-12; check its 1990–2020 values against Andres et al. −24 → −28 ‰). Test: shift the signature +2 ‰ (less depleted) and read R_d13c: the NH anomaly per ppm scales with (δ_foss − δ_atm), so R_d13c should move ~proportionally; if the table were 2–3 ‰ too depleted that alone would be 10–15 % of the gradient, not 2×. Also LUC emissions' signature and hemisphere (`luc_scale` 0.82 fitted): LUC is SH/tropics-heavy with a −25 ‰ signature — a wrong hemispheric split moves the gradient with the wrong sign for CO₂ too, which the control would show.
3. **Air-sea gross exchange, per hemisphere.** `k_w` (fitted 1912) sets the gross invasion/evasion; 09-02 found the invasion limb 2.4× too large ([[alpha_as_up_priced_not_the_answer]]) and gate Q 3σ high. Test: `k_w × {0.5, 1, 2}` and the NH/SH ocean-area split → R_d13c and gate Q together. ⚠ The SH is ocean-heavy, so a LARGER ocean exchange damps the SH more and could WIDEN the gradient — this is the test that says whether the ocean side is the wrong place to look.
4. **Photosynthetic discrimination by hemisphere.** `alpha_photo_eps` 15.6 ‰ is one global number; C4 share is higher in the SH/tropics (smaller discrimination). Test: NH 17 / SH 14 (the C3/C4-weighted split, cite Still 2003) → R_d13c; expected small (the discrimination sets the land's isotopic disequilibrium, not the NH source), but it is a 5-second scan.
5. **The station-vs-box representation** (last, and only if 1–4 leave a residual): the CO₂ control caps this at 9 %; a 2× miss cannot hide there.
