## 2. The design: one global loop, one volume W (Sv)
Legs, in the cell's idiom (every leg = W × source per-volume concentration, all three tracers, bulk, α = 1, no ¹⁴C fractionation, no ENSO term):
1. **NH surface poleward:** ML_NH → HS_NH (over `a_ml` × h_ml(t)) — as `w_thc` leg (1)
2. **NH deep-water formation:** HS_NH → HD_NH (over `a_hs` × h_hs(t)) — as leg (2)
3. **NH abyss:** HD_NH → bottom layer of the NH column — as leg (3)
4. **⭐ Deep interhemispheric limb:** bottom layer NH → bottom layer SH (over `a_ls` × dz_bottom; per-volume concentrations differ because the areas differ — write it as volume × source concentration, NOT as a diffusive exchange)
5. **SH abyss to the cold box:** bottom layer SH → HD_SH → **HS_SH** (upwelling INTO the SH cold surface box — the leg that does the work; the reverse of `w_thc` legs (3)/(2))
6. **SH surface equatorward:** HS_SH → ML_SH (the reverse of leg (1))
7. **⭐ Surface interhemispheric limb:** ML_SH → ML_NH (over `a_ml` × h_ml(t))
Volume in = out at every box by construction (one W everywhere), so a uniform column is a fixed point (the D1 test). ⚠ Legs 4 and 7 cross hemispheres: the NH's `a_ls` ≠ the SH's, so per-volume concentrations are the only consistent currency (finding 7 of the 09-16 c review was exactly `q_conv` getting this wrong).
**Options to keep OUT of the first build** (name them in the prereg as deferred): a return layer `k` above the bottom (the SO's upwelling is Circumpolar Deep Water, ~1–3 km, not the abyss — a `k_gthc` STRUCTURAL switch on the `k_thc` idiom is cheap and probably needed; build it as a parameter, probe k ∈ {bottom, mid}); a second (AABW) cell; an ENSO term (none — this is a MEAN limb).
**Naming:** `w_gthc` (Sv), `k_gthc` (1-based return layer in the SH column, default = bottom). Name must not PREFIX an existing one (`w_thc` exists; `w_gthc` is fine — check `ccx_mode_start`'s absent-name seed and `CCX_PARAM_ABSENT_OK`). Six inert names are pinned in every registered file; this one must be added to the ABSENT-OK set so registered files keep decoding.
**Contracts:** martin field only (as `w_thc`: the solved field is diffusion's fixed point); `hs_frac > 0` required (errors by name otherwise); `w_gthc = 0` emits NOTHING — every registered mode bit-reproduces (assert byte-identity of `out` on the canonical, both cores); both cores (R + C++, `test-parity`); the eigenvalue bound for substeps (`ccx_thc_eigbound()` pattern → a `ccx_gthc_eigbound()`); the flux trace classifies the new edges (label the interhemispheric legs — both endpoints are class "int"/"ml", so unlabelled they land in `int_exch`/`conv_ml`; `ccx_flux_channel()` must have a rule or the recorder errors, which is the correct failure).
**Tests (`test-gthc-loop.R`, on `test-thc-limb.R`'s pattern):** off = bit-exact; volume closure (sum of legs at every box = 0); a uniform column is a fixed point; parity R vs C++; the ¹³C and ¹⁴C edge taps close on every box with the loop on; **the mutation that matters:** with W > 0 the SH HS box's D (gate D's own reader) must FALL and the NH's must not, at fixed everything else; the conveyor/D1 guard extended (`w_gthc > 0` with `q_conv > 0` refused).
