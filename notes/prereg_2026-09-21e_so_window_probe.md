## 1. The design — ONE SH-only cell, one volume W = `w_soc` [Sv], four legs, no ML leg, no NH leg
The model already has the SO pair (HS_SH / HD_SH). Today their water budget is a TWO-WAY diffusive exchange (HS ↔ HD `u_hs` 21.8 m/yr = 18.3 Sv over `a_hs,SH` 2.65 × 10¹³ m²; HD ↔ interior `tau_q` 538 yr = 38 Sv two-way), whose partner box HD equilibrates with the air through HS (scoping 09-21 c §2). What is missing is a ONE-PASS window: deep water in, through the cold surface box, back into the interior at depth. Legs, all three tracers through `add_flux`, bulk, α₁₃ = 1, ⛔ no ¹⁴C fractionation, no ENSO term (a MEAN limb), each W × the SOURCE box's per-volume concentration over the source's OWN area and thickness NOW (the cell's idiom: D1 closes, a uniform ocean is a fixed point, volume in = out at every box):
1. **Interior transport from the return layer `k_soc_dn` to the source layer `k_soc_up`** in the SH column: if `k_dn > k_up`, upwelling `oc[j+1] → oc[j]` for j = k_up … k_dn−1 (the loop's leg 5a, bounded at k_dn instead of the bottom); if `k_dn < k_up`, DOWNWELLING `oc[j] → oc[j+1]` for j = k_dn … k_up−1; if equal, no interior leg (the window is then HD/HS fed from and returning to one layer).
2. **`oc[k_up]_SH → HD_SH`** at `y / (a_ls,SH · dz_k)` — Circumpolar Deep Water into the SO deep box (the loop's 5b).
3. **HD_SH → HS_SH** at `y / (a_hs,SH · dz_hd,SH(t))` — the outcrop into the cold surface box, the leg that does the work (the loop's 5c).
4. ⭐ **HS_SH → `oc[k_dn]_SH`** at `y / (a_hs,SH · h_hs,SH(t))` — the NEW leg: the surface water leaves at DEPTH (AAIW at k_dn 6–7, AABW at k_dn 10), NOT into the mixed layer. The loop's leg 6 (HS → ML) is what made the SH ML lighten with the cold box; here the ML is not in the cell.
**Structural names** (`p`, STRUCTURAL — not in `CCX_PARAM_TABLE`, the `w_gthc` idiom and for its three stated reasons): `w_soc = 0` (Sv), `k_soc_up = 8L` (1-based; at the canonical grid — ML 57 m; interior layer tops 57 / 109 / 183 / 285 / 428 / 628 / 909 / 1302 / 1852 / 2622 m, bottom 3700 — layer 8 is 1302–1852 m, the CDW analogue the loop used), `k_soc_dn = 10L` (the bottom = AABW). **Plus `hs_h_fac_SH = 1`**: the SH cold box's thickness relative to `h_hs` (the handoff's "per-hemisphere `h_hs`"): the pass length is `a_hs,SH · h_hs,SH / W`, and the factor is the ONE lever that shortens the pass WITHOUT raising the volume the deep rows see. Named `hs_h_fac_SH`, not `h_hs_fac_SH`: `h_hs` is an ABSENT-OK name (0 = follow `h_ml`), and a name that begins with `h_hs` would partial-match `p$h_hs` through `$` on any list that lacks it (the 09-19 m / `kn_gthc` trap). Prefix check at build: nothing in `p`, `aux` or the table begins with `soc`, `w_so`, `k_so`, `hs_h` (checked 09-21 e via `ccx_prepare()` at the canonical), and none of the new names is a prefix of an existing one.
**Aux.** `soc_on = hs_on && pump_field == "martin" && w_soc > 0` (ONE resolver in `ccx_prepare()`, marshalled; INERT under `"solved"` — the solved field is diffusion's fixed point, E's / `w_thc`'s / `w_gthc`'s contract). Refused by name: `w_soc` non-finite / negative; `k_soc_up` / `k_soc_dn` outside 1..nl; `w_soc > 0` with `hs_frac = 0`; `w_soc > 0` beside `q_conv > 0`, `w_thc > 0` or `w_gthc > 0` (one overturning representation per column); `hs_h_fac_SH` non-finite / ≤ 0; `hs_h_fac_SH ≠ 1` under the R-only seasonal cold box (`seas_ml = 2`, option B, paused) is refused rather than half-ported. `aux$h_hs` / `aux$dz_hd` STAY the scalar nominal (every test helper and six calibration scripts read them); the core reads the per-hemisphere `aux$h_hs_h[[h]]` / `aux$dz_hd_h[[h]]` (= the scalar at factor 1, bit for bit); `hs_mass_kg`, the spinup's HD starting mass, the profile likelihood's HD overlap and the three eigbounds take the per-hemisphere value.
**Flux trace.** Legs 1–4 classify on their own (`int_exch`, `ml_int`-class HS/HD legs as the loop's did); leg 4 is HS → interior, which no existing channel names — labelled **`soc_dn`** ("Southern Ocean window, the return at depth (gross)") so the ¹³C tap can read it.
**Stability.** `ccx_soc_eigbound(p, grid) = 2 × max over every SH box the cell drains of W / (area × thickness)` — layers k_up..k_dn (either order), HD_SH, HS_SH — at both seasonal extremes; exactly 0 at `w_soc = 0` or under `"solved"` (substep counts unchanged → every registered trajectory bit-identical).
**Deferred by name (not in this build):** an NH window; an ENSO term; the full 3-column model (own atmosphere coupling, own pump field, refit of every registered mode, the app's box count — the handoff's "weeks", explicitly NOT what the science needs); registration (table entry + cited prior: Talley 2013's AABW 29 Sv via `data-raw/build_u_hs_prior.R`'s chain) — owed at the REFIT tier only if the reject rule promotes it.
